# Security policy

This is an early-stage research/demo scaffold. Do not use it as an identity provider or deploy it with real user data.

Please do not report vulnerabilities containing real biometric traces or personally identifying data. Report only a minimal reproducible description and sanitized logs through a private disclosure channel when one is configured for this repository.

Known limitations include unauthenticated session bootstrap, no production TLS termination, no enrollment profile store, no similarity score, no step-up provider integration, and local-demo monitoring endpoints. These must be addressed before internet exposure.
